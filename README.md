A code-drawn front page summing up Saturday 21 November 2026: 19 verified
stories, eleven illustrated story cards, a dotted world map with location
pins, a two-column brief list, and a DATE CHECK strip excluding stories
from other days.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3 + Pillow, no network) draws the page and writes
`entry.png` (1024×1024, deterministic).

## Stories

Lead: drones hit Kyiv overnight; a double-tap strike kills 2 in Kryvyi
